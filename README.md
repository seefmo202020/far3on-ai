# فرعون AI

موقع AI فيه: شات أسئلة عامة بالعربي (DeepSeek V4.1 Flash المجاني) مع رفع صور وملفات وتسجيل صوت بيتفريغ نص + توليد صور + توليد فيديو + تحويل نص لصوت. كله شغال بمفتاح SandBase واحد.

## المميزات

- 💬 **شات ذكي** — DeepSeek V4.1 Flash (مجاني)، يفهم العربي وبيشوف الصور (Vision).
- 📎 **رفع صور وملفات في الشات** — الصور بتتحلل بالموديل، والملفات النصية محتواها بيدخل في المحادثة.
- 🎙️ **تسجيل صوت** — سجّل صوتك من المايك وهيتفريغ لنص (Wizper / Whisper V3) وجاهز للإرسال.
- 🖼️ **توليد صور** — Z-Image Turbo.
- 🎬 **توليد فيديو** — MiniMax H3 Max Turbo.
- 🔊 **تحويل نص لصوت** — Qwen 3 TTS بأصوات متعددة.

## التشغيل على Vercel (من الموبايل)

1. ارفع الملفات دي على ريبو GitHub جديد (Public أو Private).
2. افتح vercel.com وسجّل دخول بحساب GitHub.
3. Add New → Project → اختار الريبو → Deploy.
4. مهم جداً: قبل أو بعد الـDeploy روح Settings → Environment Variables وأضف:
   - Name: `SANDBASE_API_KEY`
   - Value: مفتاح SandBase بتاعك (sk-...)
   ثم Redeploy.

المفتاح مش موجود في الكود نهائياً عشان محدش يسرقه من الريبو.

## التركيب

- `index.html` — الواجهة كلها (شات / صور / فيديو / صوت).
- `api/chat.js` — بروكسي لشات DeepSeek المجاني (نص + صور).
- `api/run.js` — بروكسي لتوليد الصور والفيديو والصوت وتفريغ التسجيلات (Run API بتاع SandBase).
- `api/upload.js` — بروكسي لرفع ملفات الميديا (صوت التسجيلات) واسترجاع رابطها.

## الموديلات المستخدمة (متجربة وشغالة على المفتاح المجاني)

- شات + رؤية صور: `deepseek/deepseek-v4.1-flash:free`
- صور: `z-image/turbo`
- فيديو: `minimax/h3-max-turbo/text-to-video`
- صوت (TTS): `alibaba/qwen-3-tts/0.6b`
- تفريغ صوت (STT): `openai/wizper`
